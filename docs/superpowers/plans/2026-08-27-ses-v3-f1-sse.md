# Ses v3 (Vertex STT+TTS) + F1 (SSE akışı) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
1. **Ses v3:** cihaz-üstü STT/TTS'i emekliye ayırıp konuşma giriş/çıkışını **Vertex AI'a** taşımak — Pixel 10 Pro / Android 17 STT sorunları (watchdog, EOF flush, sentetik final) ve "TTS yazmak zorluyor" derdi kökten biter; **kişiselleştirilebilir asistan sesi** (24 Tem kesin gereksinimi) yolu açılır. CM + speaker-id inline doğrulaması aynen korunur.
2. **F1:** metin sohbette cevabın kelime kelime akması (SSE) — algılanan kalitenin en büyük kalan kaldıracı; UI revizesinin de taşıyıcısı.

**Architecture:** v2 WS köprüsü (`brain/app/voice.py`) ve otorite düzeni korunur; STT/TTS uçları değişir. PCM zaten sunucuya akıyor (utterance buffer) — v3'te aynı buffer utterance sonunda WAV'a sarılıp **Vertex Gemini 2.5-flash'e** transkribe ettirilir; yanıt metni **Cloud TTS Gemini-TTS streaming** ile PCM 24kHz chunk'larına çevrilip WS binary frame olarak cihaza akar, cihaz `AudioTrack` ile çalar (v1 playback yolu `4e05ce4^` referanslı). Metin LLM katmanı DOKUNULMAZ (ADK + CLIProxyAPI sidecar — abonelik kotası orada işe yarıyor). Kimlik: Cloud Run SA (Workload Identity, key yok). Maliyet: AI Ultra GCP kredisinden (~$5-8/ay beklenen).
